Rapid analysis for bottom-up proteomics

Pioneer identifies and quantifies precursors and proteins from data-independent acquisition (DIA) experiments. Pioneer runs through both a graphical and a command-line interface, and it scales to thousands of runs on standard desktop hardware.

Download Pioneer 0.12.2 Read the documentation

Released November 9, 2026 for macOS, Windows, and Linux.

Key features

Cross-Platform
Runs on Linux, macOS, and Windows.
Multi-Vendor
Supports Thermo Fisher, SCIEX, and Bruker instruments. See supported instruments and configurations.
GUI
Includes a graphical user interface.
Fast
Searches files many times faster than data acquisition with whole-proteome in silico libraries, even on the latest fast-scanning TOF instruments.
Scalable
Processes experiments with hundreds to thousands of runs on standard desktop hardware (32–64 GB of RAM).
Deep Proteome Coverage
Delivers high sensitivity, quantitative precision, and accuracy on diverse benchmark datasets.
Regression Testing and FDR Control
Maintains a public suite of regression tests across diverse instruments and acquisition schemes. Each tagged release triggers searches on the benchmark datasets, which include entrapment false discovery rate and false transfer rate analyses. Browse the benchmarks.
